# Kansas Host–Parasite Atlas — Version 2.2

Version 2.2 adds temporal filtering and basemap switching while preserving the Version 2.1 update workflow.

## New in Version 2.2

- Start-year and end-year sliders filter mapped specimens by collection year.
- A checkbox optionally includes records whose verbatim date lacks an unambiguous four-digit year.
- Street and topographic basemaps can be switched using the Leaflet layer control at upper right.
- Popups show the parsed collection year when available.

## Date parsing

For scientific caution, the processor only extracts explicit four-digit years (1800–2099) from `VERBATIM_DATE`.
It does not guess the century for ambiguous two-digit dates such as `6-13-85` or `March 6/05`.

Current full export:
- 7,775 total mammal records
- 7,554 georeferenced records
- 7,377 records with an unambiguous four-digit year
- parsed year range: 1892–2026
- 221 records lacking decimal coordinates
- 932 hosts with retained parasite material

## Routine update

Run:

    python scripts/process_arctos_v2.py NEW_EXPORT.csv data

Then commit the refreshed files in `data/` to GitHub.

Because the year field is generated by the processor, future exports automatically feed the time sliders.

## Local testing

Run from the project directory:

    python3 -m http.server 8000

Then open:

    http://localhost:8000

GitHub Pages will load the separated data files normally over HTTPS.
